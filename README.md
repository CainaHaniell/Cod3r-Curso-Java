## 📝 Descrição
Este repositório documenta minha jornada de aprendizado em **Java**, desde os fundamentos da linguagem até conceitos mais avançados utilizados no desenvolvimento profissional.

O conteúdo é baseado no curso **Java COMPLETO: Do Zero ao Profissional + Projetos!**, disponível na **Udemy**, utilizando a versão **Java 21**.

---

## 🎯 Objetivo
- Consolidar a lógica de programação
- Aprender Java do zero de forma estruturada
- Praticar conceitos fundamentais e intermediários
- Criar uma base sólida para Programação Orientada a Objetos e tecnologias modernas

---

## 📚 Conteúdos Abordados
O cronograma segue a metodologia do Professor Leonardo Moura Leitao, dividida nos seguintes módulos:
- Fundamentos
- Estruturas de Controle
- Classes e Métodos
- Arrays e Collections
- Orientação a Objetos
- Expressões Lambda
- Stream API  
- Outros tópicos avançados do ecossistema Java

> 📌 A organização do repositório segue as sessões do curso, divididas em pastas para facilitar o aprendizado progressivo.
