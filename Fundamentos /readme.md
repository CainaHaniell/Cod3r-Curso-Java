# ☕  Fundamentos de Java

Repositório destinado aos meus estudos iniciais em **Java**, focado nos **conceitos básicos da linguagem** e na **lógica de programação**.  
Aqui estão os primeiros passos com Java, entendendo como o código funciona e como escrever programas simples.

**📅 Registro de Estudo:**
* **Início:** 13/01/2026
* **Conclusão:** 
* **Aulas Abordadas:** 0 a 50
* **Exercícios / Desafios:** 0 a 6

---
## 📘 Conteúdos Estudados
Nesta etapa inicial, os estudos estão focados nos conceitos básicos da linguagem Java, incluindo:

- Variáveis e constantes
- Tipos primitivos
- Tipo `String`
- Conversão de tipos primitivos
- Conversão de número para `String`
- Conversão de `String` para número
- Operadores lógicos
- Operadores relacionais
- Operadores unários
- Operador ternário

> 📌 Conteúdos introdutórios voltados à compreensão da lógica e da sintaxe básica do Java.
